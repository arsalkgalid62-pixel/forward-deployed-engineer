# Forward Deployed Engineer & Claude Architect

My learning path, notes and projects for working as a **Forward Deployed Engineer (FDE)** and **Claude Architect**: designing, building and shipping production AI solutions with Claude for real customers.

## What is a Forward Deployed Engineer?

A Forward Deployed Engineer works directly with customers to turn AI into working software. The role mixes three jobs:

- **Engineer**: writes production code, integrations and deployment pipelines
- **Consultant**: understands the customer's business problem and scopes the right solution
- **Product feedback loop**: brings real-world lessons back to the product team

FDEs sit "forward" with the customer instead of behind a product roadmap. They prototype quickly, deploy into the customer's environment and stay until the solution delivers value.

## What is a Claude Architect?

A Claude Architect designs AI systems built on Anthropic's Claude models. That includes choosing the right model, structuring prompts and context, connecting Claude to tools and data, and making the system reliable, safe and cost-effective in production.

## Core Skills

### 1. Claude API & Models
- Messages API, streaming, system prompts
- Choosing between Claude models for cost, speed and capability
- Prompt caching, token counting, batch processing

### 2. Prompt & Context Engineering
- Clear instructions, examples and structured outputs
- Managing long context and retrieval
- Evaluating and iterating on prompts

### 3. Tool Use & Agents
- Tool / function calling
- Agentic loops with the Claude Agent SDK
- Multi-agent patterns and orchestration

### 4. Model Context Protocol (MCP)
- Building MCP servers to connect Claude to data and systems
- Using connectors in Claude apps and Claude Code

### 5. Claude Code
- Agentic coding workflows, skills, hooks and plugins
- Automating engineering tasks in real repositories

### 6. Production & Deployment
- Retrieval-augmented generation (RAG)
- Evaluations, monitoring and guardrails
- Security, privacy and responsible AI
- Deploying on cloud platforms (Anthropic API, AWS Bedrock, Google Vertex AI)

### 7. Customer-Facing Skills
- Discovery and requirement gathering
- Scoping, demos and proofs of concept
- Technical writing and solution documentation
