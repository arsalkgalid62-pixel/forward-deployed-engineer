# AI-102: Microsoft Azure AI Engineer Associate

Study notes, labs and practice code for the **AI-102: Designing and Implementing a Microsoft Azure AI Solution** certification exam.

## About the Exam

| | |
|---|---|
| **Certification** | Microsoft Certified: Azure AI Engineer Associate |
| **Exam code** | AI-102 |
| **Level** | Associate |
| **Languages for code** | Python, C# |

An Azure AI Engineer builds, manages and deploys AI solutions using Azure AI services, Azure AI Search and Azure OpenAI.

## Skills Measured

1. **Plan and manage an Azure AI solution**: choosing services, security, monitoring, responsible AI
2. **Implement generative AI solutions**: Azure OpenAI, Azure AI Foundry, prompt engineering, RAG
3. **Implement an agentic solution**: building agents with Azure AI Foundry Agent Service
4. **Implement computer vision solutions**: image analysis, custom vision, video indexing
5. **Implement natural language processing solutions**: text analytics, translation, speech, language understanding
6. **Implement knowledge mining and information extraction**: Azure AI Search, Document Intelligence, Content Understanding
